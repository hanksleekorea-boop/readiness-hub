현재 서비스의 범위
이 공개판은 무료 베타 진단 도구입니다. 회원가입, 서버 계정, 결제, 유료 구독 또는 판매 계약을 제공하지 않습니다. 운영 주체의 법적 신원·영업 연락처가 아직 공시되지 않았으므로 상업 판매를 시작하기 전 별도 확정이 필요합니다.

1. 약관의 목적과 적용

이 약관은 상업화 준비도 허브(이하 “서비스”) 공개 베타의 사용 조건을 설명합니다. 서비스를 사용하면 이 조건을 읽고 동의한 것으로 봅니다. 동의하지 않으면 사용을 중단하십시오.

2. 제공 기능

서비스는 모바일 앱과 PC 웹의 상업화 준비도를 자가 진단하고, 결과를 화면·JSON·CSV·인쇄물 또는 사용자가 직접 만드는 공유 링크로 내보내는 도구입니다. 점수·루브릭·관할 렌즈는 의사결정 보조자료이며 인증, 보증, 법률·세무·보안·의료 자문이 아닙니다.

3. 계정·요금·계약

현재 공개판에는 계정과 결제가 없습니다. 따라서 구독 해지, 환불 또는 서버 계정 삭제 절차도 발생하지 않습니다. 향후 계정·유료 기능을 도입하면 적용 전에 사업자 정보, 가격, 청약철회·환불 조건과 변경 약관을 별도로 고지합니다.

4. 사용자의 책임

  • 평가값과 결과의 정확성을 직접 검토하고 중요한 출시 판단은 적절한 전문가와 확인하십시오.
  • 비밀번호, 토큰, 주민등록번호, 결제정보, 건강정보 등 비밀·민감정보를 서비스명·평가자·메모·공유 링크에 입력하지 마십시오.
  • 공유 링크에는 진단 상태 전체가 들어갈 수 있으므로 수신자와 공개 범위를 사용자가 결정합니다.
  • 불법행위, 타인의 권리 침해, 서비스 방해 또는 악성 코드 배포에 사용하지 마십시오.

5. 지식재산권과 라이선스

공개 저장소의 코드와 명시된 자료에는 해당 저장소의 MIT License가 적용됩니다. 제3자 상표·자료는 각 권리자에게 귀속되며, 라이선스가 명시되지 않은 명칭·디자인의 권리가 자동 이전되지는 않습니다.

6. 베타 품질과 책임 제한

서비스는 현재 상태 그대로 제공되며 중단, 오류, 데이터 손실, 특정 목적 적합성 또는 규제 준수를 보장하지 않습니다. 관련 법이 허용하는 범위에서 운영자는 서비스 이용 또는 이용 불능으로 인한 간접·특별·결과적 손해를 책임지지 않습니다. 강행법상 배제할 수 없는 권리는 이 조항으로 제한되지 않습니다.

7. 제3자 서비스

공개 사이트는 GitHub Pages로 호스팅됩니다. 외부 링크와 GitHub의 처리는 해당 제공자의 조건·정책이 적용됩니다. 서비스는 제3자 사이트의 내용이나 지속성을 통제하지 않습니다.

8. 변경·중단·문의

중요 변경은 이 페이지의 버전과 날짜를 갱신해 공개합니다. 안전·법적 필요가 있으면 베타 기능을 변경하거나 중단할 수 있습니다. 현재 공개 지원 창구는 GitHub Issues이며 게시 내용은 공개되므로 개인정보를 적지 마십시오.
