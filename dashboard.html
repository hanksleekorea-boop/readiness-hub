⚠ 지금이 안드로이드 실기기 테스트가 필요한 시점입니다

가상 테스트로는 대체할 수 없는 것들이 있습니다. 페르소나 1000명 시뮬레이션과 브라우저 자동 검사로 로직·화면·계산은 전부 검증했지만, 아래 4가지는 실제 안드로이드 휴대폰이 있어야만 확인됩니다.

  1. 홈 화면 설치 — 크롬의 "앱 설치" 안내가 실제로 뜨는지, 아이콘·이름·전체화면 실행이 정상인지
  2. 실제 손가락 조작 — 44px 터치 영역이 충분한지, 스크롤 중 오터치가 나는지
  3. 실기기 화면 — 노치·둥근 모서리·제스처 바 영역에 버튼이 가리는지 (하단 이동줄이 특히 위험)
  4. 오프라인 동작 — 비행기 모드에서 앱이 켜지는지 (임시 저장 장치가 실제로 작동하는지)

테스트 방법: 위 QR 중 "모바일(앱)"을 안드로이드 크롬으로 찍고 → 우측 상단 메뉴 → "앱 설치" → 홈 화면 아이콘 실행 → 비행기 모드로 재실행. 각 단계 결과를 알려주시면 즉시 수정합니다.

현재: 공개 배포가 완료되어 지금 바로 이 실기기 테스트를 수행할 수 있습니다.
