계정·로컬 데이터 삭제

최종 갱신 2026-08-15 · beta 0.6.3

현재 공개판에는 서버 계정이 없습니다.
회원가입·로그인·서버 프로필이 없으므로 운영자에게 삭제를 요청할 계정 데이터도 없습니다. 아래 기능은 이 브라우저 출처에 남을 수 있는 로컬 저장소, 진단 공유 링크 조각과 오프라인 앱 캐시를 삭제합니다.

이 버튼이 삭제하는 것

  • 이 사이트 출처의 localStorage와 sessionStorage
  • 이 사이트가 만든 crh- 이름의 오프라인 캐시
  • crh로 시작하는 IndexedDB 데이터베이스가 있는 경우 해당 데이터베이스
  • 현재 주소의 #d=… 공유 상태 조각
삭제되지 않는 것
이미 내려받은 JSON/CSV·PDF, 다른 사람에게 보낸 공유 링크·복사본, 브라우저 동기화 기록, GitHub의 보안 방문 로그는 이 페이지에서 삭제할 수 없습니다. 해당 저장 위치나 제공자에게서 직접 삭제해야 합니다.
취소하고 서비스로 돌아가기

수동 삭제 대안

  1. 브라우저의 사이트 정보 또는 설정에서 이 사이트를 찾습니다.
  2. “데이터 삭제”, “저장공간 삭제” 또는 “권한 및 저장공간 초기화”를 선택합니다.
  3. 홈 화면에 설치했다면 앱 아이콘을 제거합니다.

GitHub 방문 로그 관련 권리는 GitHub 개인정보 보호정책의 문의 절차를 이용하십시오. 서비스 관련 공개 문의는 GitHub Issues를 이용하되 개인정보를 게시하지 마십시오.
