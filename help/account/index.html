Google 로그인·무료 가입과 내 계정

현재 공개판의 인증 상태
Readiness Hub와 정확히 연결된 기존 인증 제공자가 아직 확인되지 않았습니다. 로그인 화면과 안전한 인증 경계는 준비되어 있지만, 외부 인증 연결 전에는 로그인 대신 설정 안내가 표시됩니다. 진단 기능은 로그인 없이 계속 사용할 수 있습니다.

로그인하면 달라지는 것

  • Google 최초 로그인은 무료 가입과 같은 한 번의 흐름입니다.
  • 표시 이름은 사용자가 ‘이름·설정 저장’을 누른 경우에만 인증 제공자에 전달됩니다.
  • 표시 언어와 하루 목표는 이 기기의 브라우저에만 저장됩니다.
  • 진단 결과와 메모는 로그인 전후에 자동 업로드·자동 병합되지 않습니다.

수동 백업

PC의 ‘JSON 저장’ 또는 모바일의 ‘백업 파일 만들기’를 눌렀을 때만 파일이 만들어집니다. 인증 상태와 인증용 열쇠 문자열은 백업에 포함하지 않습니다. 불러오기는 사용자가 직접 파일을 고른 경우에만 시작됩니다.

계정 보안

Google 비밀번호, 2단계 인증, 로그인 기기는 Google 계정에서 관리합니다. 이 서비스는 비밀번호·인증 응답·세션 열쇠 문자열을 직접 보관하지 않습니다.
