Readiness Hub 사용법

서비스의 출시 위험을 증거로 찾고, 가장 중요한 문제부터 고친 뒤 다시 확인하는 무료 도구입니다.

가장 빠른 사용 순서

  1. 퀵체크: 서비스 방향과 필수 조건 3개를 먼저 답합니다.
  2. 진단: 모바일과 PC 웹을 따로 선택하고 확실한 항목부터 점수를 입력합니다.
  3. 증거: 주소·확인일·담당 역할을 남기되 비밀번호·쿠키·개인정보는 넣지 않습니다.
  4. 결과: 전체 점수보다 미통과 필수 조건과 상위 갭 3개를 먼저 봅니다.
  5. 실행: 고급 작업대에서 담당·기한·증거를 연결하고 재검증합니다.
  6. 백업: JSON 파일을 내려받아 안전한 위치에 보관하고 복원 시험을 합니다.
