막혔을 때 바로 확인

8가지 공통 상태와 해결 방법

각 상태마다 무슨 일인지, 내 데이터가 안전한지, 다음에 무엇을 누를지 설명합니다.

공통 원칙: Readiness Hub 무료판의 진단 값은 기본적으로 현재 브라우저에 저장됩니다. 중요한 결과는 JSON 파일로 내려받아 별도 보관하세요.

1. 처음이라 내용이 없음

무슨 일인가요?
아직 점수를 입력하지 않은 정상 상태입니다.
데이터는 안전한가요?
삭제된 것이 아닙니다.
다음 행동
퀵체크 12문항부터 시작하세요.

2. 자료를 불러오는 중

무슨 일인가요?
기준·콘텐츠 JSON을 읽고 있습니다.
데이터는 안전한가요?
기존 입력은 그대로입니다.
다음 행동
잠시 기다리고 계속되면 새로고침하세요.

3. 저장 완료

무슨 일인가요?
JSON 백업 파일이 내려받아졌습니다.
데이터는 안전한가요?
다운로드 폴더에서 파일 존재와 크기를 확인해야 합니다.
다음 행동
파일을 다시 불러오는 복원 시험을 하세요.

4. 불러오기 실패

무슨 일인가요?
파일 형식이 다르거나 내용이 손상됐습니다.
데이터는 안전한가요?
현재 진단 값은 덮어쓰지 않습니다.
다음 행동
원본을 보존하고 다른 백업을 선택하세요.

5. 오프라인

무슨 일인가요?
인터넷 연결이 끊겼습니다.
데이터는 안전한가요?
현재 브라우저 입력은 남지만 새 외부 자료는 확인할 수 없습니다.
다음 행동
연결 후 재시도하고 JSON을 백업하세요.

6. 콘텐츠 로드 오류

무슨 일인가요?
쉬운 설명 또는 사례 파일을 읽지 못했습니다.
데이터는 안전한가요?
진단 점수와는 분리되어 있습니다.
다음 행동
연결·주소를 확인하고 새로고침하세요.

7. 비교 계산 불가

무슨 일인가요?
같은 기준의 비교 대상이 3개 미만입니다.
데이터는 안전한가요?
오류가 아니라 과장 방지 상태입니다.
다음 행동
공개 근거가 있는 비교 서비스를 추가하거나 그대로 미확인으로 두세요.

8. 필수 조건 미통과

무슨 일인가요?
전체 점수와 관계없이 3점 미만인 출시 차단 조건이 있습니다.
데이터는 안전한가요?
점수는 보존됩니다.
다음 행동
필수 조건의 해결 순서와 좋은 증거를 펼쳐 실행하세요.
