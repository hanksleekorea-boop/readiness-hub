한눈에 보기
이 후보판에는 Google 로그인·내 계정 화면이 있지만 실제 인증 공급자가 연결되지 않아 회원 계정이나 서버 프로필이 생성되지 않습니다. 진단 상태는 브라우저에서 처리되고, 계정 화면의 표시 언어·하루 목표만 이 브라우저에 저장됩니다. 사용자가 직접 JSON/CSV를 내려받거나 공유 링크를 만들 때만 선택한 위치로 나갑니다.
상업 운영 전 남은 고지
운영 주체의 법적 명칭·주소·비공개 개인정보 문의 채널이 아직 확정되지 않았습니다. 이 페이지는 현재 실제 기술 동작을 투명하게 설명하지만, 그 정보가 확정되기 전에는 상업 운영용 최종 개인정보 처리방침이 아닙니다.

1. 처리 구조와 항목

상황데이터처리 위치·목적보유
진단 사용서비스명, 평가자 표기, 평가일, 점수, 메모, 승인자 표기현재 브라우저 메모리에서 진단 계산페이지를 닫거나 새로 불러오면 소멸. 자동 서버 저장 없음
JSON/CSV 내보내기·가져오기사용자가 선택한 진단 상태기기 안에서 파일 생성·읽기내려받은 파일은 사용자가 삭제할 때까지 해당 기기에 존재
공유 링크진단 상태 전체를 인코딩한 URL 조각(#d=…)사용자가 복사·전달한 수신자의 브라우저에서 복원서비스 서버는 URL 조각을 수신하지 않음. 복사본·브라우저 기록은 사용자와 수신자가 관리
공개 사이트 방문IP 주소 및 통상적인 웹 사용 기록GitHub Pages의 보안·호스팅 운영GitHub 정책에 따름
오프라인 기능정적 HTML·JS·렌즈 파일브라우저 Cache Storage새 버전에서 교체하거나 사용자가 삭제할 때까지. 진단 입력값은 캐시하지 않음
내 계정 로컬 설정표시 언어, 하루 목표이 브라우저의 localStorage에서 화면 설정 유지사용자가 삭제 페이지나 브라우저 설정에서 지울 때까지
Google 로그인 후보 기능현재 없음인증 공급자가 연결되지 않아 계정·토큰·프로필을 처리하지 않음해당 없음. 실제 연결 전에 별도 고지 갱신 필요
학습 안내서의 Google 광고IP 주소, 브라우저·기기 정보, 광고 요청·표시·상호작용 정보, 쿠키 또는 유사 저장 기술Google AdSense가 광고 제공, 부정 사용 방지, 빈도·성과 측정과 사용자 선택 적용을 위해 처리할 수 있음. 진단 답변·메모·점수는 광고 대상으로 전달하지 않음Google 정책과 사용자의 동의·거부 선택에 따름

2. 수집 목적·법적 근거

이 서비스 운영자가 진단 입력값을 서버로 수집하지 않습니다. 기기 내 처리는 사용자가 요청한 진단·내보내기 기능을 수행하기 위한 것입니다. GitHub Pages 방문 로그는 호스팅 제공자인 GitHub가 보안 목적으로 처리하며 자세한 근거와 권리는 GitHub 정책을 확인해야 합니다.

3. 쿠키·분석·판매·광고

서비스 운영자는 진단 입력값을 판매하거나 교차 맥락 행동광고 목적으로 공유하지 않습니다. Google AdSense 광고 코드는 학습 안내서에만 제한하며, PC·모바일 진단·대시보드·작업대·계정·삭제·정책 화면에서는 광고 요청을 보내지 않습니다. 광고 요청은 맞춤설정을 끈 상태를 기본으로 하며 브라우저의 전역 개인정보 보호 신호(Global Privacy Control)를 존중합니다. 다만 Google이 쿠키나 유사 기술을 사용할 수 있고 실제 처리 범위는 지역, Google 설정, 동의 선택과 광고 재고에 따라 달라집니다. 자세한 적용 범위와 상태는 광고 운영 원칙에서 확인할 수 있습니다.

4. 제공·국외 처리·수탁

운영자가 진단 입력값을 제3자에게 자동 제공하지 않습니다. 다만 사용자가 공유 링크·파일을 보내면 선택한 수신자에게 직접 제공됩니다. 공개 사이트는 미국 기업 GitHub, Inc.의 GitHub Pages를 사용하므로 방문 로그 처리·이전은 GitHub General Privacy Statement를 따릅니다. 학습 안내서에서 광고를 허용한 경우 Google LLC와 관련 광고 서비스 제공자가 위 표의 광고 데이터를 처리할 수 있으며 Google 개인정보처리방침이 적용됩니다. 유럽경제지역·영국·스위스와 미국 일부 주에서는 Google 인증 동의 관리 도구(CMP)의 메시지 게시 여부를 운영 전에 확인해야 합니다.

5. 안전조치와 데이터 최소화

현재 서버 계정과 진단 데이터베이스를 두지 않고, 입력값의 자동 영구 저장을 하지 않으며, 정적 리소스만 오프라인 캐시합니다. 로그인 공급자가 없을 때 기능을 차단하고 진단은 계속 쓸 수 있게 분리했습니다. 비밀·민감정보 입력을 금지하고 공유 전 사용자가 내용을 검토하도록 안내합니다. 인터넷 전송에는 GitHub Pages의 HTTPS를 사용합니다.

6. 삭제·권리 행사

계정·로컬 데이터 삭제 페이지에서 이 출처의 로컬 저장 영역과 오프라인 캐시를 지울 수 있습니다. 내보낸 파일·공유받은 복사본은 저장 위치에서 직접 삭제해야 합니다. GitHub가 보유한 방문 로그에 관한 요청은 GitHub 개인정보 보호 창구를 이용하십시오. 광고 선택은 광고 운영 원칙의 “광고 개인정보 선택 열기”에서 다시 열 수 있으며, Google 메시지가 아직 게시되지 않았다면 해당 사실을 화면에 표시합니다.

7. 아동·변경·문의

서비스는 아동을 대상으로 설계되지 않았고 연령 정보도 요청하지 않습니다. 방침을 바꾸면 버전과 시행일을 갱신합니다. 현재 공개 문의 창구는 GitHub Issues이며 공개 게시판이므로 개인정보를 적지 마십시오. 비공개 개인정보 문의 채널은 상업 운영 전에 반드시 추가됩니다.

8. 작성 근거

고지 구조는 대한민국 개인정보 보호법 제3조·제30조와 개인정보보호위원회 작성지침, GDPR 제13조의 투명성 항목, FTC의 데이터 최소화 원칙을 참고했습니다. 이 표시는 특정 법률의 적용 여부 또는 준수 인증을 뜻하지 않습니다.
