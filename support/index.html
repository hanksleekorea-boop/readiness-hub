무료 공개 지원

지원과 문의

비공개 문의 채널은 아직 확정되지 않았습니다.
현재 확인 가능한 창구는 공개 GitHub Issues뿐입니다. 개인정보·비밀 URL·계정 정보는 올리지 마세요.

현재 지원 범위

  • 공개 기능 오류와 재현 절차
  • 197개 기준·40개 필수 조건의 문구 오류
  • 접근성·모바일 화면·오프라인 동작 문제
  • 자동 분석 엔진의 입력·출력 오류

문의 방법

공개 오류 접수에서 비밀값을 제거한 재현 절차만 남겨 주세요. 비공개 문의가 필요한 개인정보·삭제·보안 신고는 전용 채널이 공시되기 전까지 접수 완료로 표시하지 않습니다.

응답 약속

현재는 공식 응답 시간 약속(SLA)이 없습니다. 확인되지 않은 응답 시간을 만들지 않으며, 운영 주체와 담당 채널이 확정되면 실제 가능한 범위만 갱신합니다.
